# Coffee-Sales
An interactive Plotly dashboard that visualizes coffee sales across weekdays and months, enriched with hover tooltips showing coffee-type breakdowns. Built with pandas, Plotly, and clean time-based feature engineering, this project demonstrates how to turn transactional data into actionable insights.

## 🔍 Features
- Time-based feature extraction (month, weekday, hour)
- Aggregation of coffee sales by weekday and month
- Interactive Plotly heatmap with custom hover tooltips
- Clean, reusable pipeline for dashboard-ready visuals

## 📁 Structure
- `data/`: Sample dataset (`coffeedata.csv`)
- `notebooks/`: Annotated Jupyter notebook
- `visuals/`: Static preview images
